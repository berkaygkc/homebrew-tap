# Homebrew tap

Casks for [berkaygkc](https://github.com/berkaygkc)'s apps.

```sh
brew install --cask berkaygkc/tap/mystat
brew install --cask berkaygkc/tap/yabbistir
```

| Cask | App |
|---|---|
| `mystat` | [mystat](https://github.com/berkaygkc/mystat), a calm system monitor for the macOS menu bar |
| `yabbistir` | [yabbistir](https://github.com/berkaygkc/yabbistir), a keyboard-first clipboard history that opens under your text caret |
